### Verified corrections

- A failed personalization quarantine could be swallowed, allowing subsequent learning
  to overwrite the original profile. Propagate storage errors; start fresh only after
  successful quarantine. A pre-fix isolated probe reproduced the overwrite.
- Interrupted dictation published its stop cue before microphone shutdown. Publish only
  after stop completes; paused-stop regressions cover sleep, route and permission events.
- Malformed third-party Accessibility ranges could overflow insertion verification.
  Validate ranges and counts before Foundation operations.
- Cancellation after paste key-down could restore the old clipboard before the target
  consumed it. Distinguish dispatched paste interruption; retain the transcript or a
  newer clipboard without claiming verified insertion.
- Switching Vocabulary from Dictionary to Learning and back erased unfinished input.
  The parent now owns the draft; native editor/segment-control regression failed before
  the fix and passes afterward.
- Reconfirming a learned correction discarded newly supplied capitalization. Keep the
  correction identity while applying the latest explicit replacement.
- Repeated meeting callbacks copied the accumulated Array before every append. Mutate
  dictionary-held samples in place. Synthetic tests preserve both sources, chunk
  boundaries, final tails, timestamp gaps and rate changes.
- Meeting summary cancellation now owns the preflight as well as model generation.
  Failed meeting saves offer explicit confirmed discard after export, preserving saved
  data and captured audio; close and quit never discard automatically.
- Uninstall force-killed the app before meeting/draft shutdown could finish. It now waits
  and aborts without deletion on refused quit. Isolated command-shim tests cover both paths.

## Release follow-up: local Notes

create/edit/search notes, export plain text, and move notes to Recently Deleted or
restore them. This is phase 1 of the competitive proposal, not meeting capture or

## Architecture and scope

Reviewed all 41 first-party Swift source files, the package/dependency boundary,
build/install/uninstall scripts, CI/release workflows, privacy/security documents,
and the associated test coverage. The core audit covered session state and recovery,
audio, text insertion, settings/history, personalization, models/downloads, text
formatting, and diagnostics. The app audit covered coordinator lifecycle, hotkeys,
permissions, recording cues, overlays, menus, settings, and the correction window.

Keep the existing architecture: two production targets, one pinned dependency,
native adapters, one dictation state machine, deterministic text cleanup, and
explicit recovery. Its complexity mostly protects real audio, Accessibility,
clipboard, and storage failure modes. A broad rewrite would remove tested behavior
without a demonstrated benefit. Third-party package internals were not exhaustively
audited; the dependency and artifact trust boundaries were reviewed.

## Confirmed fixes

| Finding | Change | Evidence |
| --- | --- | --- |
| P1: concurrent stop events or an audio-route change could finalize the same recording twice | Reserve the state transition before awaiting audio shutdown; publish the stopped cue only after shutdown | `concurrentStopsFinalizeAndInsertOnlyOnce`, `routeChangeDuringAudioFinalizationDoesNotStopTheRecordingAgain` |
| P2: an already-global learned correction became app-specific after another confirmation | Remove the branch that narrowed global scope | `crossApplicationCorrectionStaysGlobalAfterFurtherConfirmations` |
| P2: a failed Teach save left the editor open without explaining the failure there | Show a local failure message, retain the edit, and clear the message on retry | `teachViewModelDismissesOnlyAfterSuccessfulSave` |
| P2: the resizable Teach window contained a fixed-width editor | Let the editor grow with the native window | `productionTeachEditorExpandsWithItsWindow` |

For the first two findings, three new tests failed on the original implementation
with nine failed assertions, while the original 188 tests passed.
Those regression cases pass after the fixes. The UI findings were verified against
the concrete view/model code and native window tests.
